# Flycode 0.1

Flycode 是一个从零开始、由参与者逐步共同塑造的网站。这个版本是可以在本机运行的 MVP，包含：

- 公开项目首页
- 当前阶段与成长时间线
- 网友提交提案
- ✅ 主持人审核提案
- ✅ 主持人开启投票
- ✅ 网友投票（同一浏览器每轮一次）
- ✅ 主持人公布决定
- ✅ 主持人发布进展、开启下一轮
- ✅ 提案审查工作台：待审核、已公开、未采用分栏
- ✅ 提案列表独立滚动，支持批量通过、批量不采用、批量删除
- ✅ 未采用提案可批量重新审查，恢复为待审核
- ✅ 导出项目数据

## 运行方式

需要安装 Node.js 18 或更高版本。

在终端中执行：

```bash
cd C:/Users/l2104/flycode
npm start
```

然后用浏览器打开：<http://localhost:4173>

停止服务时，在终端按 `Ctrl + C`。

### 手机局域网测试

电脑和手机连接同一个 Wi-Fi 后，手机访问服务启动时终端显示的网络地址，例如：

```text
http://192.168.10.10:4173
```

当前版本只适合本机或局域网测试。电脑关机、服务停止或网络切换后，手机地址会失效；正式公开需要把服务和数据迁移到云端。

## 自动测试

确保服务已经运行后，在另一个终端执行：

```bash
npm test
```

测试会临时创建提案，验证管理员权限、批量不采用、重新审查和永久删除，结束后自动清理测试数据。

## 管理入口

点击网站右上角的“管理入口”。本机默认管理密钥是：

```text
flycode-local
```

正式部署之前必须通过环境变量修改它：

```bash
FLYCODE_ADMIN_KEY="换成一段长而随机的密钥" npm start
```

当前版本的管理密钥是用于本机体验的简化方案，不适合直接公开部署。

## 数据在哪里

第一次启动后，服务会自动创建：

```text
data/db.json
```

提案、投票、阶段和成长记录都保存在这里。这个文件已经被 `.gitignore` 排除，避免把活动数据意外提交到代码仓库。管理工作台里的“导出项目数据”可以生成备份。

## 第一轮建议流程

1. 把网站链接放到视频简介或置顶评论。
2. 邀请大家回答“你希望 Flycode 先做什么？”。
3. 你在管理入口审核收到的提案。
4. 通过几个有代表性的提案后开启投票。
5. 投票结束后公布一个决定，并写清楚下一步。
6. 做出一个可见的改变，再发布进展记录。
7. 开启下一轮。

## 下一步

这个 MVP 先用本地 JSON 文件验证活动机制。确定有人持续参与后，再把数据层迁移到面向中国大陆用户的云服务，并增加正式管理员登录、内容审核、防刷和图片存储。不要把当前版本直接部署到公网：它使用本地 JSON 数据库，默认管理密钥只适合本机体验。
